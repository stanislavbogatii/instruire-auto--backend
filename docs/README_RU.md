## 🔗 Быстрые ссылки

### Файлы конфигурации

| Файл | Назначение |
|------|-----------|
| `.env` | Переменные окружения (локально) |
| `package.json` | Зависимости и npm scripts |
| `tsconfig.json` | TypeScript конфигурация |
| `eslint.config.mjs` | ESLint правила |
| `.prettierrc` | Prettier форматирование |
| `nest-cli.json` | NestJS конфигурация |
| `prisma/schema.prisma` | Модель БД |

### Основные директории

| Директория | Назначение |
|-----------|-----------|
| `src/` | Исходный код приложения |
| `src/auth/` | Аутентификация, JWT |
| `src/users/` | Управление пользователями |
| `src/groups/` | Группы студентов |
| `src/reservations/` | Система бронирования |
| `src/exams/` | Экзамены и вопросы |
| `src/instructors/` | Профили инструкторов |
| `src/cars/` | Управление машинами |
| `src/common/` | Общие сервисы, decorators |
| `src/prisma/` | PrismaService |
| `prisma/` | Миграции БД |
| `test/` | E2E тесты |
| `docs/` | Документация (этот каталог) |

### API Endpoints

| Endpoint | Назначение |
|----------|-----------|
| `http://localhost:8888/api` | Base API URL |
| `http://localhost:8888/api-docs` | **Swagger UI** (тестируйте здесь!) |
| `npx prisma studio` | GUI для БД (http://localhost:5555) |
